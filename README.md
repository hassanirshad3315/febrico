# Fabrico Style Studio

Build a complete, production-ready, full-stack luxury Pakistani women's fashion e-commerce platform for FABRICO.

IMPORTANT:

This is NOT a simple landing page.

This is NOT a static UI mockup.

This is NOT a generic Shopify clone.

Build a real, scalable, database-driven fashion commerce application with:

- Premium customer storefront

- Advanced product discovery

- Collection management

- Editorial fashion content

- Dynamic homepage merchandising

- WhatsApp commerce

- Customer interaction tracking

- Order/inquiry management

- Admin CMS

- Analytics dashboard

- Product and inventory management

- Media management

- Promotional campaign management

- SEO management

- Authentication

- Secure backend

- Responsive design

- High-end animations and transitions

The final product should feel like a sophisticated international luxury fashion website while remaining specifically designed for the Pakistani women's fashion market.

Take design and UX inspiration from the principles used by premium fashion retailers such as Net-A-Porter, Aritzia and COS, while also incorporating the category structure and shopping patterns commonly used by Pakistani fashion retailers such as SAPPHIRE and Limelight.

DO NOT copy their branding, layouts, assets, wording, logos, or proprietary design.

Use the underlying UX principles as inspiration and create an original FABRICO identity.
